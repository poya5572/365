سیستم اخبار زنده — نکته مهم و صادقانه
----------------------------------------
چک کردم: روی دامنه‌ی فعلی شما (365-e4r.pages.dev) اخبار همچنان ثابت بودند — چون این
دامنه Cloudflare Pages است و Cloudflare Pages نمی‌تواند PHP یا یک سرور پایتون مداوم
اجرا کند، پس api/news_server.py و api/news_proxy.php روی این هاست کار نمی‌کنند.

خبر خوب: چون خود Cloudflare Pages از «Cloudflare Pages Functions» (جاوااسکریپت سرورلس،
رایگان) پشتیبانی می‌کند، یک نسخه‌ی سازگار با همین هاست ساختم:

  functions/api/news.js
  functions/api/prices.js

فقط کافیست پوشه‌ی functions را کنار index.html در پروژه‌ی Cloudflare Pages خودتان قرار
دهید (یا کل این zip را دوباره در همان پروژه دیپلوی کنید) — Cloudflare خودش این مسیرها
را زیر /api/news و /api/prices فعال می‌کند، کاملاً رایگان و بدون نیاز به سرور جداگانه.

نتیجه: اخبار صفحه اصلی هر ۳۰ دقیقه یک‌بار به‌صورت خودکار تازه می‌شود (کش لبه‌ی Cloudflare
با max-age=1800 تنظیم شده)، و قیمت‌ها هم علاوه بر Nobitex مستقیم، از یک پروکسی سریع‌تر و
پایدارتر عبور می‌کنند.

درخواست شما «به‌روزرسانی مداوم اخبار بدون دخالت دستی، از طریق API» بود. این کاملاً پیاده‌سازی شد،
اما یک واقعیت فنی مهم هست که باید بدانید:

خبرهای گوگل نیوز (Google News RSS) به‌صورت رایگان و بدون نیاز به کلید API در دسترسند، و نسخه‌ی
فارسی آن‌ها (hl=fa) از قبل به فارسی هستند — یعنی نیازی به «ترجمه‌ی جداگانه» نیست، چون گوگل
نیوز خودش نسخه‌ی فارسی هر خبر را برمی‌گرداند. این را در api/news_server.py و api/news_proxy.php
پیاده کردم.

اما این فیدها را مرورگر کاربر نمی‌تواند مستقیماً بخواند (برخلاف قیمت‌ها که یک API عمومی
با CORS آزاد داشت) — پس برای واقعاً «زنده‌شدن» اخبار روی سایت شما، حتماً باید یکی از این دو
بک‌اند را روی هاست خودتان فعال کنید:

  روش ۱ — هاست اشتراکی (PHP):
    پوشه api را در public_html آپلود کنید. صفحه به‌صورت خودکار به api/news_proxy.php
    و api/prices_proxy.php وصل می‌شود اگر مسیر /api/news و /api/prices را روی همان‌ها
    ریدایرکت کنید (یا مستقیم در assets/script.js آدرس‌ها را به مسیر واقعی فایل‌ها تغییر دهید).

  روش ۲ — VPS/سرور اختصاصی (Python):
    cd api && pip install -r requirements.txt
    python api_server.py       (پورت ۵۰۰۰، قیمت‌ها)
    python news_server.py      (پورت ۵۰۰۱، اخبار)
    یا با gunicorn برای محیط تولید.

اگر هیچ‌کدام از این دو بک‌اند فعال نباشند، سایت کاملاً سالم کار می‌کند اما:
  - قیمت‌ها از API عمومی نوبیتکس مستقیماً در مرورگر گرفته می‌شوند (چون CORS آزاد دارد).
  - اخبار همان کارت‌های نمونه‌ی فعلی باقی می‌مانند (چون RSS گوگل نیوز از مرورگر مستقیم قابل
    خواندن نیست) — تا وقتی یکی از بک‌اندهای بالا را فعال کنید.

اگر بخواهید از منابع خبری انگلیسی/بین‌المللی هم استفاده کنید و آن‌ها را ماشینی به فارسی ترجمه
کنید، تابع translate_text() در news_server.py برای همین آماده شده — فقط باید یک سرویس ترجمه
(مثلاً Google Cloud Translate یا یک نمونه‌ی خودمیزبانِ LibreTranslate) و کلید API آن را وصل کنید؛
پیش‌فرض فعلی هیچ سرویس پولی را صدا نمی‌زند.

جدول تفصیلی طلا/سکه/ارز و خودرو
----------------------------------
در صفحه category.html، وقتی کاربر دسته «طلا و سکه»، «ارز و رمزارز» یا «قیمت خودرو» را
انتخاب می‌کند (لینک‌های ?c=gold ، ?c=currency ، ?c=car)، به‌جای اخبار عمومی، یک جدول
تفصیلی و شکیل با ردیف‌های جداگانه برای هر نوع سکه/طلا/ارز یا هر خودرو نمایش داده می‌شود.
ردیف‌های دلار، یورو، تتر، طلای ۱۸ عیار و بیت‌کوین به‌صورت خودکار از همان سیستم قیمت زنده
(نوبیتکس یا بک‌اند شما) به‌روز می‌شوند؛ بقیه ردیف‌ها (نیم‌سکه، ربع‌سکه، پوند، درهم، لیر،
و قیمت خودروها) عکس لحظه‌ای مرجع هستند چون API رایگان و بدون‌کلید برای آن‌ها در دسترس
نبود — مشابه توضیح بخش اخبار، اگر بخواهید این‌ها هم کاملاً زنده شوند باید منبع/API آن‌ها
را وصل کنید.

رفع احتمالی مشکل «سایت بدون استایل / زشت باز می‌شود»
--------------------------------------------------------
از عکسی که فرستادید مشخص بود صفحه با فونت پیش‌فرض مرورگر و بدون رنگ/چیدمان
باز می‌شه — یعنی فایل assets/style.css اصلاً لود نمی‌شده. رایج‌ترین دلیل این
مشکل، مسیرهای نسبی (assets/style.css) هست که بسته به اینکه صفحه در چه
مسیری سرو بشه ممکنه بشکنه. برای رفعش، تمام ارجاع‌ها به style.css و script.js
رو به مسیر مطلق (/assets/style.css) تغییر دادم — این تضمین می‌کنه مسیر همیشه
از ریشه‌ی سایت خونده بشه، صرف‌نظر از این‌که کاربر کدوم صفحه رو باز کرده.
بعد از این دیپلوی، اگه بازم مشکل بود، لطفاً یه اسکرین‌شات دیگه بفرستید تا
دقیق‌تر بررسی کنم.

بازارهای جهانی و نفت
----------------------
یک ویجت جدید به صفحه اصلی اضافه شد («بازارهای جهانی و نفت») که نفت برنت،
نفت WTI، S&P 500، داوجونز، نزدک، نیک‌کی ۲۲۵ و بورس استانبول رو نشون می‌ده —
دقیقاً شبیه چیزی که توی اسکرین‌شات تلگرام فرستادید. این از یک اندپوینت
غیررسمی یاهو فایننس می‌گیره (رایگان و بدون کلید، ولی چون رسمی نیست ممکنه
گاهی یاهو محدودش کنه — به همین خاطر کاملاً در try/catch پوشیده شده که اگر
قطع شد، بقیه‌ی سایت خراب نشه). این بخش هم هر ۳۰ دقیقه به‌روز می‌شه.

اتصال newsdata.io و gnews.io — نیاز به کار خودتان دارد
----------------------------------------------------------
کدش رو کامل نوشتم و توی api/news.js (نسخه Cloudflare Function) وصل کردم، اما
من نمی‌تونم برای شما توی این سایت‌ها حساب بسازم یا کلید API بگیرم — این کار
حتماً باید با ایمیل خودتون انجام بشه (هر دو رایگانن، نیازی به کارت بانکی
ندارن):

  ۱) به https://newsdata.io بروید → Sign Up → کلید API رایگان رو کپی کنید
  ۲) به https://gnews.io بروید → Get API Key → کلید رایگان رو کپی کنید
  ۳) توی داشبورد Cloudflare Pages: پروژه‌ی سایتتون → Settings →
     Environment variables → Add variable:
        NEWSDATA_API_KEY = <کلیدی که از newsdata.io گرفتید>
        GNEWS_API_KEY     = <کلیدی که از gnews.io گرفتید>
  ۴) دوباره دیپلوی کنید (Cloudflare خودش تغییرات env رو توی دیپلوی بعدی اعمال می‌کنه)

بعد از این کار، اخبار صفحه اصلی ترکیبی از Google News + newsdata.io + gnews.io
می‌شه — بدون این‌که هیچ کد دیگه‌ای رو دست بزنید.

ترجمه‌ی خودکار خبر انگلیسی → فارسی
-------------------------------------
خبرهایی که از newsdata.io/gnews.io میان و فارسی نیستن، خودکار با
LibreTranslate (سرویس رایگان و متن‌باز، بدون کلید) ترجمه می‌شن. این سرویس
عمومیه و گاهی کند یا موقتاً در دسترس نیست — اگه ترجمه شکست بخوره، متن اصلی
(انگلیسی) نشون داده می‌شه، نه خطا.

اگه کیفیت ترجمه‌ی بهتری می‌خواید (مثل گوگل ترنسلیت واقعی)، باید یک حساب
Google Cloud با صورت‌حساب فعال بسازید و Cloud Translation API رو در اون فعال
کنید (این سرویس رایگان نیست، هرچند ماهانه یه سهمیه‌ی رایگان کوچیک داره)،
سپس کلیدش رو به‌همین شکل با نام GOOGLE_TRANSLATE_API_KEY در Environment
variables اضافه کنید — کدش از قبل آماده‌ست و خودکار اونو با اولویت بالاتر
از LibreTranslate امتحان می‌کنه.

کلیک روی خبر = نمایش هم‌زمان ترجمه و متن اصلی
--------------------------------------------------
حالا با کلیک روی هر کارت خبر (توی صفحه اصلی)، یک پنجره باز می‌شه که تیتر و
خلاصه‌ی فارسی رو نشون می‌ده؛ اگه اون خبر ترجمه‌شده بود (یعنی از newsdata.io
یا gnews.io اومده بود)، یک بخش «مشاهده متن اصلی (انگلیسی)» هم زیرش هست که
می‌تونید باز کنید و متن اصلی رو ببینید. یه دکمه هم برای رفتن به خبر کامل در
سایت منبع اصلی گذاشته شده (چون این سرویس‌ها فقط تیتر و خلاصه می‌دن، نه متن
کامل مقاله).

مقاوم‌سازی در برابر خطا (طبق درخواست‌تون)
---------------------------------------------
همه‌ی این منابع (Google News، newsdata.io، gnews.io، یاهو فایننس، نوبیتکس،
LibreTranslate) کاملاً مستقل و در try/catch جدا پوشیده شدن — یعنی اگه یکی
از این سرویس‌ها قطع بشه یا کلیدش تنظیم نشده باشه، فقط همون بخش خالی می‌مونه
و بقیه‌ی سایت (منو، فیلترها، قیمت‌ها، ثبت‌آگهی، بازارچه) کاملاً سالم کار
می‌کنه. هیچ‌کدوم از این ویژگی‌ها نمی‌تونن سایت رو "بشکنن"، چون هیچ‌کدوم روی
عملکرد بقیه‌ی صفحه تأثیر نمی‌ذارن.
